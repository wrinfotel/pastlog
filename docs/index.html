// why pastlog

Built on one bet: your agent history is worth searching.

Weeks of decisions, fixes and context are buried in JSONL files and SQLite databases across five different tools. pastlog reads them all — without an index, a server, or a single network call.

01

Five agents, one search

Claude Code, Codex CLI, Gemini CLI, OpenCode and ZCode — one query fans out across every project on the machine. It reads tool calls and tool outputs too, not just the chat.

02

Nothing leaves your machine

The binary contains no network code at all — no HTTP client, no TLS. A build-time test (TestNoNetworkDeps) fails the moment one appears in the dependency graph.

03

Read-only, enforced

pastlog never writes to agent storage. SQLite sources open strictly with mode=ro, and the guarantee is backed by tests, not good intentions.

04

No index to babysit

Pure streaming search — nothing to build, update or store. Measured at ≈178 MB/s over a 500 MB corpus on a dev machine; run it once, get an answer now.

05

First-class Windows

Not an afterthought: race-enabled CI on Windows, amd64 + arm64 release binaries, path handling normalized on every command.

06

One static binary

No runtime, no dependencies, no config files, no accounts. Drop it on your PATH and it just finds your data — pastlog stats shows where your tokens go.

// install

Three ways in. All under a minute.

pastlog ships as a single static binary — no runtime, no dependencies, no config files.

1 · Release binary

Prebuilt for six platform targets, SHA256 checksums included.

tar xzf pastlog_0.1.0_linux_amd64.tar.gz
sudo install pastlog /usr/local/bin/
pastlog version

2 · Go install

Any platform with Go 1.27+.

go install \
  github.com/wrinfotel/pastlog/cmd/pastlog@latest

3 · From source

Clone and build — produces a single binary.

git clone https://github.com/wrinfotel/pastlog
cd pastlog
go build ./cmd/pastlog

Homebrew and Scoop formulas are planned — see the roadmap. macOS note: release binaries are not notarized in v0.1; if Gatekeeper objects, run xattr -d com.apple.quarantine ./pastlog or allow it in System Settings.

// faq

The questions that actually matter.

Is anything uploaded?
No. There is no network code in the binary at all — no HTTP client, no TLS, no telemetry, no update checks. The project's own test suite fails the build if net/http, crypto/tls or any third-party HTTP package ever appears in the dependency graph.
Does it modify my logs?
No — read-only by design and enforced by tests. Adapters only open files for reading, and SQLite-backed sources (OpenCode, ZCode) open with mode=ro; a write attempt is refused by the driver.
Is Windows really supported?
Yes, first-class: CI runs the race-enabled test suite on Windows, releases include windows/amd64 and windows/arm64 binaries, and --project matches forward and back slashes alike.
How fast is it, really?
No index, pure streaming: ≈178 MB/s literal search and ≈71 MB/s regex over a 500 MB corpus on a dev machine (warm cache). Full benchmark table and caveats are in the README's Performance section.
What does it cost?
Nothing. MIT-licensed open source — clone it, fork it, ship it.
